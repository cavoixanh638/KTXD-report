# Dữ liệu nguồn (chỉ lưu tại máy người sử dụng)

Không commit dữ liệu Excel thật, báo cáo chứa thông tin nội bộ, hoặc tệp sao lưu phiên làm việc lên GitHub. Lưu nguồn bên ngoài repository và chọn qua giao diện ứng dụng.

Dữ liệu giả lập không nhạy cảm cho automated tests có thể bổ sung trong `tests/fixtures/` khi lập trình.
